# Dashboard Quran App

Monorepo for the Quran Karim public website, administrator dashboard, and native Android application.

- `apps/web` — Next.js public website and admin dashboard.
- `apps/android` — Android application and release packaging.
- `supabase` — database schema and Edge Functions.
- `.github/workflows` — GitHub Pages and Android release automation.

Run `npm install` then `npm run dev` for the web app. Use `npm run build:android` for Android.
